## Findings considered and rejected

Do not re-audit these as new work unless the facts change:

- **`npm audit` extract-zip as a Tessel runtime issue** — Electron’s install-time unzip of its own checksummed official zip, not an app upload sink. Plan 017 upgrades EOL Electron (which is also the audit’s fixAvailable). Do not add a Tessel “zip sandbox.”
- **Validating renderer-supplied paths as if this were a networked app** — no HTML sink today; the user chooses local files. Plan 011 hardens About/main **navigation**. If you later load remote content in a preload window, revisit IPC path allowlisting then.
- **Spectron / Playwright-Electron as the first test layer** — Spectron is abandoned; full Electron E2E is disproportionate (~960 lines of app JS). Plan 001 uses `node:test` on extracted helpers. Optional one-window smoke is not a prerequisite.
- **TypeScript or a frontend framework** — vanilla main + renderer is small; a bundler would not shrink the ffmpeg core.
- **`require('slash')` crashes startup** — slash 5 is ESM-only but Node ≥22.12 can load it. It is unused. Delete it in plan 008; do not pin `slash@3` “to be safe.”
- **`var vidPathN` vs `window['vidPath'+n]` split-brain** — they alias in a classic non-module script. Still a footgun if someone adds `type="module"`; fold into an array refactor only as part of plan 020 if needed, not as a standalone bug.
- **2×2 convert with only slots 5–9 filled throwing** — dropzones 5–9 are `display: none` and `switchGrid` clears those paths. Not reachable. Do not add a special-case test that requires hidden slots to be filled.
- **Framework rewrite, merging the two CSS files, fluent-ffmpeg `.run()` as the encoder** — spawn + `-filter_complex` is the live path.
- **Hardware encode** — no evidence the bundled ffmpeg binary supports videotoolbox/nvenc in this app’s argv. (Originally written for FFmpeg 4.4; still true for ffmpeg-static 6.0.)

Follow-up audit (`c2b112f`) — considered and rejected:

- **Row leftover pixels** — 720p/1080p heights divide evenly by 2 and 3; only columns needed the 015 fix. Revisit if a non-divisible height is added.
- **IPC path allowlisting / dialog tokens** — still a local user-chosen-file app; no HTML sink. 030 restricts ffmpeg **protocols**, which is different.
- **Electron 45, nodemon→electron --watch, eslint/prettier, TypeScript, Spectron/Playwright as the first test layer** — still not worth it at ~3k LOC.
- **Upgrade FFmpeg 6.0 → 7/9 and hash-pin ffmpeg-static’s GitHub download** — supply-chain/EOL is real; L migration, not planned in 027–043.
- **Electron fuses, CSP, CI `workflow_dispatch` split, `ELECTRON_SKIP_BINARY_DOWNLOAD` on the test job** — valid packaging/CI hygiene; not in the follow-up finding table.
- **Cover-art first `Duration:`** — LOW; not in the follow-up finding table. Progress chunk splits are plan 034.
- **Duplicate `-i` / `split` for the same file in many slots** — real CPU win; not in the finding table (033 only uniqued **probes**).
- **`plans/` as agent prompt-injection** — first-party docs; review plan diffs like code, no executor plan.
- **About window missing explicit `webSecurity`** — Electron default is `true`.
- **Signed/notarized macOS** — permanently deferred (`plans/DEFERRED.md`). Do not list it as a direction finding again.
